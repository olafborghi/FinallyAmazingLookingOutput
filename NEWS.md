# falo (development version)

# falo 0.2.0

* New `descriptive_table()` builds a descriptive sample overview table (metric
  and categorical variables, optional survey weights) as a tinytable object.

# falo 0.1.0

* First version with `theme_allround()`, set in Public Sans.
* Public Sans is downloaded from Google Fonts on first load and registered per
  weight; `falo_svg_fonts()` embeds it in saved SVG files.
